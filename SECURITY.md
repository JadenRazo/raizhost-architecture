# Security policy

## Supported code

Security fixes are made against the latest `main` branch. Historical diagrams and decision records describe points in time and are not maintained release lines.

## Reporting

Use GitHub private vulnerability reporting through the repository's **Security** tab when available. Otherwise email `contact@jadenrazo.dev` with the affected path, impact, and a minimal reproduction.

Do not open a public issue containing credentials, client or customer data, account identifiers, private hostnames, non-public infrastructure inventory, or a working exploit.

## Scope

This repository is a public architecture record rather than the production source tree. Reports about sensitive-data exposure in the published diagrams or documentation, unsafe example commands, and workflow supply-chain risks are in scope. Report vulnerabilities in the private production platform through the same private channel without adding operational details to a public issue.
